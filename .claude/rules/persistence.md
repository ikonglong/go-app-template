# Persistence Layer Coding Guide

## Generic Building Blocks

Two generics carry the boilerplate; each concrete aggregate adapter is small.

### `baseRepo[D, R]` (`base_repo.go`)

Implements `domain.IRepo[D]` over a single go-jet table whose primary key is a single string column. Held state:

```go
type baseRepo[D any, R any] struct {
    db          qrm.DB                  // *sql.DB or *sql.Tx
    table       postgres.Table
    allCols     postgres.ColumnList
    mutableCols postgres.ColumnList
    idCol       postgres.ColumnString

    mapper IMapper[D, R]
    idOf   func(*D) string              // PK extractor — works around private fields

    notFound error                      // aggregate sentinel
}
```

Behaviors worth remembering when extending:

- **`Add` uses `INSERT ... RETURNING all_columns`** and writes the persisted row back into `*e`, so DB-defaulted fields (timestamps with `DEFAULT NOW()`, server-side enums) end up reflected in the in-memory instance after one round trip.
- **`Update` and `Delete` return `r.notFound` when `RowsAffected == 0`.** Don't wrap that — let `errors.Is` do the work upstream.
- **`findOne(ctx, where)`** is the canonical helper for aggregate-specific finders. It translates `qrm.ErrNoRows → r.notFound`. Call it from concrete repos rather than rebuilding the SELECT/limit/error-translation pattern.

### `IMapper[D, R]` (`mapper.go`)

```go
type IMapper[D any, R any] interface {
    ToRecord(*D) *R
    ToDomain(*R) *D
}
```

The mapper is its own type with its own constructor. **Mapper dependencies (Clock, IDGen, hasher, value-object factories) live on the mapper, not on the repo.** That keeps `NewAccountRepo`'s signature stable as the mapping logic grows.

## Concrete Aggregate Adapter

For each aggregate, three things in this directory:

1. **`xxx_repo.go`** — concrete repo embedding `*baseRepo[Domain, Record]`, plus aggregate-specific finders.
2. **`xxx_mapper.go`** — concrete mapper, its constructor, and an internal per-call `recordBuilder`.
3. **Compile-time assertions** at the bottom of each file:

```go
var (
    _ IMapper[domain.Account, record.Account] = (*AccountMapper)(nil)
    _ domain.IAccountVisitor                  = (*recordBuilder)(nil)
)
// xxx_repo.go:
var _ domain.IAccountRepo = (*AccountRepo)(nil)
```

## Mapping Discipline

### `ToRecord`: drive the visitor

```go
func (*AccountMapper) ToRecord(a *domain.Account) *record.Account {
    b := &recordBuilder{}
    a.Accept(b)
    return &b.rec
}
```

`recordBuilder` is a per-call accumulator that **explicitly implements every method** of `IAccountVisitor`. **Do not embed `domain.DefaultAccountVisitor` here.** A full-fidelity mapper that silently drops new fields is a regression. The compile-time `var _ domain.IAccountVisitor = (*recordBuilder)(nil)` makes a forgotten method a build error.

### `ToDomain`: call the rebuild factory

```go
func (*AccountMapper) ToDomain(r *record.Account) *domain.Account {
    return domain.RebuildAccount(r.ID, r.Name, /* ... */)
}
```

Direct struct-literal construction won't compile — domain fields are private. `RebuildAccount` is the contract.

## Generated Code

Generated by `db-migrations/gen.sh` — see `.claude/rules/codegen.md`. Layout:

```
internal/adapter/repo/jet/gen/<dbname>/<schema>/
    record/    domain-side struct mirrors (jet's "model", repackaged)
    table/     column descriptors and SQL builders
```

- The package is **`record`** (not `model`). In a DDD-flavored codebase `model` means "domain model", which is the entity, not the row.
- Never hand-edit generated files. Regenerate via `gen.sh` whenever the schema changes.
